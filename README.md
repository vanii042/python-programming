# Python Programming — Beginner to Advanced

A beginner-friendly collection of standalone Python programs for learning, college practice, and GitHub.

## Topics
- `01-Basics`: input/output, arithmetic, calculator, temperature, area
- `02-Conditions-Loops`: loops, factorial, Fibonacci, prime, palindrome
- `03-Patterns`: star and number patterns
- `04-Functions-Recursion`: functions, recursion, GCD and LCM
- `05-Lists-Tuples`: list operations, searching, sorting, tuples
- `06-Strings`: palindrome, vowels, anagrams, word count
- `07-Dictionaries-Sets`: dictionaries, word frequency, set operations
- `08-Searching-Sorting`: binary search and sorting algorithms
- `09-Functions-Lambda`: lambda, map and filter
- `10-OOP`: classes, inheritance, polymorphism, encapsulation
- `11-Modules-Exceptions`: math, date/time, exception handling
- `12-File-Handling`: reading, writing and appending files
- `13-Data-Structures`: stack, queue and linked list
- `14-Algorithms`: BFS, DFS and Kadane's algorithm
- `15-Mini-Projects`: number guessing, rock-paper-scissors, quiz and to-do list

## Requirements
- Python 3.10+ recommended
- No third-party packages are required

## Run a program
Run one file at a time from the repository folder:

```bash
python 01-Basics/hello_world.py
```

On Windows, `py` can also be used:

```powershell
py 01-Basics/hello_world.py
```

Each file is a separate program. Follow its input prompts. Some programs create files in the current directory.

## Suggested learning order
Start with Basics and Conditions, then Patterns and Functions, Lists and Strings, Searching and Sorting, OOP, File Handling, Data Structures, Algorithms, and Mini Projects.

## Note
These are simple learning examples, not every possible Python problem. Try changing the inputs and adding comments as you learn.
